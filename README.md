# Rainy Stadium

## Дисклеймер об использовании ИИ

При разработке сайта использовалась ИИ-модель **GPT-6.1 Sol Medium** в приложении **OpenAI Codex**.

Модель использовалась для:

- вёрстки сайта на HTML и CSS по предоставленным макетам Figma и PDF;
- экспорта и подключения графики из Figma;
- адаптации страницы для мобильных устройств, планшетов и широких экранов;
- реализации анимации телефонной трубки по клику;
- исправления ошибок отображения и выделения текста, проверки страницы в браузере;
- оформления исходного кода и выполнения операций Git по запросам автора.

Исходные макеты и графические материалы были предоставлены автором проекта. ИИ использовался как инструмент для реализации сайта и внесения согласованных правок.
